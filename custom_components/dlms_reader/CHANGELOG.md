# Historia zmian integracji

Wersje integracji i dodatku są niezależne. Ta historia dotyczy pakietu
instalowanego przez HACS.

## 0.2.1

- Instalacja przez HACS po dodaniu repozytorium niestandardowego.
- Kategoria energia oraz metadane i ikony integracji zgodne z wymaganiami HA.
- Instrukcja instalacji, aktualizacji i usunięcia integracji.
- Licencja GPL-2.0 dołączona do pakietu.

## 0.2.0

- Encje pomiarowe pobierane z API dodatku bez dodatkowej sesji DLMS.
- Jednostki, klasy urządzeń i klasy stanu przekazywane przez dodatek.
- Wyświetlanie do pięciu miejsc po przecinku przy zachowaniu precyzji danych.
- Wykrywanie dodatku, konfiguracja ręczna i zmiana tokena API.
- Przenoszenie encji MQTT z zachowaniem identyfikatorów i historii.
